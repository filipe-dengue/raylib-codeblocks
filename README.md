# Projeto Raylib para Code::Blocks
Passo a passo para rodar o projeto:

1º - Baixe tanto o projeto do jogo quanto o compilador, os extraia no seu computado

2º - Usando o code::blocks, abra o projeto

3º - No code::blocks vá em configurações -> compilador... (ou em settings -> compiler... se ele estiver em inglês)

4º - Após isso vá na aba "Toolchais executables"

5º - Nessa aba vá no botão com os 3 pontos ("...") e seleciona a pasta do compilador novo

6º - Agora você pode fechar essa janela e executar o jogo
